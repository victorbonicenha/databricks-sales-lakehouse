## Descrição para currículo

```text
Projeto de Engenharia de Dados com Databricks, PySpark e Delta Lake, simulando uma pipeline de vendas em arquitetura Medallion. O fluxo realiza ingestão de arquivos CSV/JSON na camada Bronze, tratamento e validação na Silver, separação de registros rejeitados e criação de tabelas Gold para análise de faturamento, categorias, clientes e pagamentos.
```

## Explicação rápida para entrevista

```text
Esse projeto simula uma pipeline de vendas em Databricks. Primeiro eu faço a ingestão dos dados crus na Bronze. Depois trato os dados na Silver, convertendo tipos, removendo duplicados, validando regras e separando registros rejeitados. Na Gold, crio tabelas analíticas para responder perguntas de negócio, como faturamento diário, vendas por categoria, top clientes e resumo de pagamentos. Também criei checks simples de qualidade para validar duplicidade, campos obrigatórios e divergência de valores.
```
